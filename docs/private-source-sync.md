# 来源环境应用同步与任务进度

2026-10-16 用户明确要求完整修复客户端来源身份丢失、目标版本未选择和任务状态覆盖三个缺陷，核对公开版本后按 PATCH 发布。GitHub Release 与平台更新服务均确认当前 macOS 最新为 0.12.0，本次修正版为 0.12.1，仍仅发布 macOS。依赖、锁文件解析、平台服务、Bundle 和本地应用版本不变，不引入兼容回退、额外可用性探测或权限变更。

## 来源和版本

未公开应用从 ConnectorInstallRecord.installSource 读取完整环境和应用身份。详情页展示该身份，不把下载解压临时路径当成可复用安装来源。同步界面明确显示当前版本并要求选择准确的目标 SemVer；同步当前版本表示重新安装它，不再显示无法兑现的“拉取最新”。目标版本来自操作者选择，不硬编码某个应用或版本，不枚举猜测版本，不自动切换来源或降级。来源环境 Owner 在实际安装请求中确认目标冻结版本、调用者授权及制品合同。

前端将原应用身份和用户指定版本共同传入 installSource 与安装请求。后端在环境下载请求前校验请求 appId/version 与 SourceVersion 完全相符（包括 build metadata）。原来源及安装替换的授权、安全与并发校验继续执行；缺少身份显式失败，不回退 sourcePath/sourceReference、临时目录或其他来源。现有未公开来源确认提示明确包含来源、当前版本、目标版本和覆盖行为。

## 任务状态

安装任务由宿主内存中的任务所有者维护；每个任务初始 revision=1，每次更新在同一锁内递增修订号，终态不再接受后续更新。任务进度 channel、创建命令返回和任务列表快照都使用同一个 revision。前端只接受同任务更高的修订，终态不可被回退。创建命令携带的 queued 对象无论先到还是后到，都不能覆盖较新的 resolving/failed/succeeded。不同任务的重试按创建顺序展示，不把旧任务的迟到更新当作最新尝试。没有新增轮询、恢复缓存或安装重放。

## 验证与交付

前端回归执行真实的 lifecycle/catalog action，覆盖进度先于及晚于命令返回两种顺序、缺失/错误来源、准确目标版本与不修改原安装记录。纯状态测试覆盖同毫秒不同修订、重复与旧快照、终态保持、独立重试。Rust 回归覆盖所有者修订、终态不可变以及来源和请求应用/版本不一致时的明确拒绝。发布质量、双架构签名/公证、OSS 和更新元数据验证由唯一 release-bridge-agent 工作流完成；设备实际升级和手机号搜索、中文公开错误详情另行验收，不能以发布成功代替实机通过。
