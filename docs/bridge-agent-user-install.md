# 百积木个人用户安装指南

本文面向第一次使用百积木的个人用户。百积木是本机连接工具，用来把当前电脑安全连接到百积木平台；它本身不是对话客户端。

## 安装

1. 打开公共下载页：

```text
https://www.baijimu.com/download/
```

2. 下载适合自己电脑系统的安装包：
   - Windows：下载 `.msi`，安装完成后桌面会出现“百积木”图标
   - macOS：下载 `.dmg`
   - Linux：下载 `.deb` 或 `.AppImage`
3. 打开安装包，按系统提示完成安装。
4. 启动百积木。

## 卸载

- Windows：打开百积木的“诊断 → 系统”，点击“卸载百积木”。选择“完全卸载”会同时删除设备配置、登录凭证、本地应用、Baijimu CLI 和相关数据；选择“保留数据”可以在重新安装后继续使用原有配置。
- macOS：先退出百积木，再从“应用程序”删除“百积木.app”。
- Linux：使用系统包管理器卸载 `.deb`，或退出后删除 `.AppImage`。

完全卸载不会递归删除用户自行指定的外部日志目录。

## 授权

1. 按页面提示登录你的百积木账号。
2. 确认授权当前设备。
3. 授权完成后，百积木会显示已授权或已连接。

## 下一步

百积木当前没有内置对话输入框。授权完成后，在百积木首页点击“打开控制台”，进入百积木控制台后再打开 Agent 对话页面。

如果需要安装 Codex，在百积木平台的 Agent 对话里复制并发送：

```text
请打开并阅读这个文档：
https://docs.baijimu.com/features/codex-device-install/index.html

严格按照文档里的 Codex 设备安装流程，
为当前工作区已连接的设备完整安装并验证 Codex。

不要自行猜测步骤。
如果无法读取网页、无法访问设备执行能力，或缺少用户授权，
请先说明原因并停止。
```

后续按提示继续即可。Codex 安装不依赖市场技能；你不需要安装任何 Codex 技能，也不需要配置默认助理。平台 Agent 会直接读取公开执行文档，安装并打开 ChatGPT desktop app、配置 Codex 终端、路由和本地认证。你不需要自己下载 ChatGPT/Codex，也不需要复制 API Key。

## 遇到问题

如果升级后界面空白，不要“完全卸载”，也不要删除配置或应用数据。

- 有“界面暂时无法显示”恢复页：先重试界面，或检查并安装官方更新。检查失败会显示原因，可在网络恢复后再次操作。
- 页面完全无法操作：从系统托盘选择“检查更新与修复”或“打开启动日志”。该入口不依赖业务界面。旧版客户端可能没有这个入口。
- 旧版本已经白屏或系统 WebView 无法启动：从上面的官方公共下载页下载修复版本的完整安装包，先退出客户端，再覆盖安装。Windows 运行新版 `.msi`；macOS 打开新版 `.dmg`，将百积木替换到“应用程序”。不要以删除数据或降级为前提。

0.6.18 的界面重构存在配置加载后崩溃的问题；对应的完整修复版本为 0.6.20（0.6.19 因安装验证的比对基准错误未完成全平台发布）。旧客户端不能仅靠服务器发版自动获得新的恢复界面，需要更新或覆盖安装。网络/DNS 故障与该渲染缺陷是不同问题：网络不可用时不能承诺下载成功，但应保留错误说明、重试、日志和外部安装恢复路径。

把错误提示或截图发给支持人员。不要发送完整密钥、访问令牌或敏感业务数据。
