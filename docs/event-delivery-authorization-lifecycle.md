# 可靠事件与授权生命周期

2026-09-30，用户确认 Bridge 0.10.1 PATCH 修复边界：本地控制与浏览器授权入口不依赖平台身份，可靠事件交接必须依赖完整授权身份。

旧版本升级以及首次登录前，配置可以没有 environmentKey、workspaceId 或设备凭据。运行时必须启动本地控制服务并显示 AuthorizationRequired；不连接 Relay，不打开事件数据库，不启动投递工作器，不自动启动连接器。事件入口返回明确的 503 授权要求，不返回接收确认。不存在匿名队列、默认环境或由域名推测身份的兼容分支。

浏览器授权保存环境、工作区、设备与凭据后，沿既有停止/重启流程打开对应身份作用域的 SQLite 队列，启动消费组订阅与重试。完整身份下的数据库失败仍是错误，不能变成未授权或降级为内存投递。已授权设备离线时仍能持久接收事件；联网不是授权身份存在的前提。切换身份不投递原作用域事件。

0.10.0 的不可变标签及部分构建制品不覆盖。0.10.1 通过完整质量门禁及真实 Windows MSI 旧版升级测试后，才用于联合发布。
