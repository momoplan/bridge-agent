# 市场读取显式选择工作区

Windows 客户端 0.18.0 的应用列表显示更新检查失败，错误详情为
`PUBLIC_OPENRESTY_INVALID_REQUEST`。市场 URL 已携带业务参数 `workspaceId`，
但 `MarketReader` 未发送 Partner 网关要求的 `X-Workspace-Id` 请求头。
Agent 在线及业务 query 均不能替代入口工作区选择器。

只读线上对照使用同一授权、工作区和正式 v4 目录接口：不带该请求头时返回上述错误，
带上相同工作区时返回 7 个合同版本 4.0.0 的市场条目。HTTP 状态均为 200，
应依据 CModel 的业务错误码判断结果。凭据未写入源码、日志或回执。

修复归客户端市场请求构造。将私有来源读取已有的工作区 HTTP 客户端构造器移到公共请求模块，
市场目录、精确版本和制品读取共同使用它；请求头与业务 query 使用同一个已配置工作区。
保留 HTTPS、禁重定向、超时、PAT 认证及请求追踪。网关继续验证请求头与凭据范围，
来源 Owner 继续完成授权。此修复不修改网关、市场合同、依赖或授权文件，不新增失败回退。

回归测试通过本地实际 HTTP 传输验证目录、精确版本、制品读取前的版本检查和制品下载均发送
工作区、Bearer 和追踪头；已有私有版本与制品测试验证原路径保持正确。
本地仅测试 macOS 原生目标。正式发布流程负责完整质量检查、真实市场目录与精确版本验收、
Windows 检查、签名、安装升级恢复、OSS 分发和更新元数据验证。

独立客户端补丁 0.18.1 修复上述请求缺失，仅选择 Windows 发布。
它不是平台 Component 或 Bundle；其发布不变更 CLI 捆绑来源和其他平台制品。
发布流水线通过和设备实际升级后的页面验证分别记录，不能互相替代。
