# 客户端设置（0.11.2）

设置采用左侧分类菜单：通用、设备与账号、连接、运行、事件与存储、关于与更新。
未授权设备也可以打开设置；托盘菜单提供“设置…”入口。

- 通用中的“开机自启动”直接读取操作系统登录项。切换立即写入系统并回读验证，不参与配置表单保存。
- 客户端启动和升级只检查自启动状态，不创建或重新开启登录项。已有登录项保持原状态；全新安装默认关闭，由用户显式开启。
- 设备、连接、运行、事件与存储使用独立草稿及“保存更改”。离开当前分类或设置页时，可以保存并继续、放弃并继续或继续编辑。
- `save_settings_section` 读取磁盘中的最新配置，只应用当前分类允许的已改动字段，并沿用完整配置校验。凭证、工作区归属和安装应用不接受设置表单覆盖；运行参数不会覆盖事件策略。
- 表单保存不自动重启当前运行服务。连接、解释器等运行参数将在下次启动服务时使用；事件策略按现有运行时的策略加载机制生效。
- 自启动系统写入或回读失败会显示错误并重新读取状态；表单保存失败保留草稿，不跳转页面。

验证覆盖未授权访问、自启动开关与失败、分类保存隔离、未保存导航保护、事件/运行参数隔离和窄窗口布局。后端测试覆盖越界字段、凭证保留和系统自启动写入回读。
